# Lista Familiar — Project Instructions

## Architecture
- **Backend**: NestJS + Prisma + PostgreSQL. Modules: Auth, FamilyGroups, Lists, Items.
- **iOS App**: SwiftUI, iOS 18+, no SwiftData (all data server-backed). Only the JWT token is persisted locally (Keychain).

## Design
- **Theme**: Green grocery theme. Brand #2E7D4F, accent #E07A2E, background #F6F4EE, SF Pro Rounded throughout.
- **All UI text in Spanish** — every label, button, placeholder, message, alert, tab name, empty state, category name.

## Models
- Categories enum: FRUTAS_VERDURAS, LACTEOS_HUEVOS, CARNES_PESCADO, PANADERIA, LIMPIEZA, BEBIDAS, DESPENSA, OTROS
- `ListItemDto` and `ShoppingListSummaryDto` extended with `Identifiable` conformance via `ModelExtensions.swift`
- `JSONValue` helper extension for extracting `UserPublicDto` from JSONValue? fields (purchasedBy, addedBy, createdBy)

## Navigation
- RootView switches based on SessionModel state: SplashView → AuthFlowView → FamilyGroupSetupView → MainTabView
- MainTabView: 2 tabs (Listas, Ajustes)
- ListsHomeView uses NavigationStack(path) with `.navigationDestination(for: String.self)` to push ListDetailView

## Polling
- ListsHomeView: every 5s
- ListDetailView: every 3s

## Auth Flow
- JWT stored in Keychain via APIClient.shared.authToken
- On any 401: clear token, set user = nil → returns to login
